# Security

If you find a security issue in a Rare Geometry kit, for example a way for save data or settings to be read or changed by someone they should not be available to, please do not open a public issue.

Email the details to marklromano@outlook.com instead. Include the kit and its version, the Unity version, and the steps that show the problem. You will receive a reply within 2 business days, and the issue will be fixed or documented before it is discussed publicly.
